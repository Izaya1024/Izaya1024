## Hola, soy Matías

Ingeniero en Informática de Chile. Trabajo en desarrollo web full stack, sobre todo con Node.js, React y PostgreSQL, y me interesan especialmente las bases de datos y la calidad del software, es decir, que lo que se construye esté probado, documentado y sea fácil de mantener.

### Experiencia reciente

En mi último proyecto trabajé sobre un sistema web de gestión con varios roles de usuario, que recibí ya construido y que fui modernizando por etapas.

- Migración de la base de datos de MariaDB a PostgreSQL, con el traspaso de los datos y la corrección de efectos de carrera mediante transacciones.
- Paso del frontend de HTML y JavaScript sin framework a React con Vite.
- Auditoría de seguridad, con control de permisos por rol, sesiones con cierre remoto, recuperación de contraseña y límite de intentos de inicio de sesión.
- Pruebas automatizadas unitarias, de integración y de extremo a extremo, incluidas pruebas de accesibilidad y de carga.
- Adecuación del tratamiento de datos personales a la Ley 21.719 de protección de datos.
- Desarrollo de requerimientos nuevos y documentación técnica del sistema, con requerimientos funcionales, diagramas e informes.
